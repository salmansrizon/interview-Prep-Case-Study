# 📊 ShopSmart Retail Data Storyboard

## সহজ ভাষায় Project Overview

এই notebook project-এ retail data-এর **Visual EDA** এবং **Descriptive Statistics** ব্যবহার করে business-এর health, trend এবং unusual pattern বোঝানো হয়েছে। Raw table দেখে যে insight ধরা কঠিন, chart এবং summary metric সেটি সহজ করে।

## কী শিখবেন?

- Mean, Median, Mode দিয়ে data-এর center বোঝা
- Variance ও Standard Deviation দিয়ে spread measure করা
- Histogram, Boxplot এবং category chart interpret করা
- Outlier এবং skewed distribution identify করা
- Chart-কে business story-তে convert করা

## কীভাবে Run করবেন?

```powershell
cd "week 3\Class 1 Project"
python -m pip install jupyter pandas numpy matplotlib seaborn
python -m jupyter notebook week3_class6_project.ipynb
```

Notebook-এর cell উপর থেকে নিচে run করুন। প্রতিটি chart-এর পরে written observation-এর সাথে নিজের interpretation compare করুন।
