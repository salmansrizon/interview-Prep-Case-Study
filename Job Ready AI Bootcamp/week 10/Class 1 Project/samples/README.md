# Sample inputs

All candidates and organizations here are fictional.

1. In the app's **Match** tab, upload `job_description.txt` under **Job Description**.
2. Set **How many CVs do you want to compare?** to **5**.
3. Upload one `cv_*.txt` file in each **Candidate CVs** slot, and use the filename as its optional label.
4. Click **Match** and inspect the ranking and scores.

The set includes an NLP engineer (direct match), a search engineer (related work with different wording), a data analyst and backend engineer (partial matches), and a chef (unrelated role). Treat the order of partial matches as a model result to inspect, not a guaranteed hiring judgment.
