from scipy.stats import beta as beta_dist
import numpy as np

# ডেটা বানানো
data = np.random.normal(mu, sigma, n)

# Z-score ও percentile
z = (x - data.mean()) / data.std()
pct = stats.norm.cdf(z) * 100

# Frequentist CI
se = np.sqrt(p * (1 - p) / n)
ci = (p - 1.96*se, p + 1.96*se)

# Bayesian credible interval

Glossary — এই কোর্সে শব্দগুলোর মানে

শব্দমানে
Normal Distributionঘণ্টা আকৃতির বণ্টন, μ ও σ দিয়ে সম্পূর্ণ বর্ণিত
μ (mean)গড় — বণ্টনের কেন্দ্র
σ (std dev)ছড়ানোর মাপ — বণ্টনের প্রস্থ
Z-scoreগড় থেকে কত σ দূরে
Standardizationডেটাকে mean=0, std=1 এ রূপান্তর
Outlierঅস্বাভাবিক ভ্যালু, সাধারণত |Z| > 3
Percentileকত শতাংশ ডেটা এর নিচে আছে
FrequentistProbability = দীর্ঘমেয়াদে ঘটার হার
Law of Large Numbersনমুনা বাড়লে অনুমান আসল মানে পৌঁছায়
Standard Error (SE)অনুমানের নিজস্ব অনিশ্চয়তা
Confidence IntervalFrequentist রেঞ্জ; ১০০টার ৯৫টায় আসল মান ধরে
BayesianProbability = বিশ্বাসের মাত্রা, প্রমাণে আপডেট হয়
Priorপ্রমাণের আগের বিশ্বাস
Likelihoodঅনুমান সত্যি হলে এই প্রমাণ পাওয়ার সম্ভাবনা
Posteriorপ্রমাণের পরের আপডেট করা বিশ্বাস
Credible IntervalBayesian রেঞ্জ; “আসল মান এখানে থাকার ৯৫% সম্ভাবনা”
Beta distribution০–১ এর মধ্যে থাকা বণ্টন; accuracy/probability-র অনিশ্চয়তা প্রকাশে
Confidence Scoreমডেল নিজের উত্তরে কতটা নিশ্চিত (০–১)
CalibrationConfidence আর বাস্তব accuracy মেলে কিনা
Thresholdযে score-এর উপরে স্বয়ংক্রিয় সিদ্ধান্ত নেওয়া হবে
False Positiveনেই এমন জিনিসকে “আছে” বলা
